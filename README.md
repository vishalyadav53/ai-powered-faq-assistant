# AI-Powered FAQ Assistant (MERN Stack)

A fast, scalable full-stack AI Chatbot built using React, Node.js, Express, and MongoDB. It features an intelligent fallback mechanism to operate in zero-delay production mode.

## 🚀 Features Implemented
1. **Interactive Chat UI:** Built with React.js using smooth state management for dynamic updates.
2. **Robust Backend:** Node.js & Express.js architecture with clear routing and controller structures.
3. **Database Framework:** Integrated with MongoDB models for storing conversation histories.
4. **Asynchronous Optimization:** Optimized backend operations to ensure **0-delay instant responses** on the frontend.
5. **Hybrid Fallback System:** Implemented a resilient local-memory mechanism that handles network or database connection statuses smoothly.

## 🌟 Bonus Features
- **Dark Mode Feature:** Fully functioning theme toggle (Light/Dark Mode) directly inside the interface.

## 🛠️ Installation & Setup

### Prerequisites
- Node.js (v18 or above)

### Backend Setup
1. Navigate to backend: `cd ai-faq-backend`
2. Install packages: `npm install`
3. Configure `.env` file with `PORT=5000`
4. Start Server: `npx nodemon server.js`

### Frontend Setup
1. Navigate to frontend: `cd ai-faq-frontend`
2. Install packages: `npm install`
3. Start React App: `npm start`
